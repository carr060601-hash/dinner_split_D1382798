## 二、程式用途

本程式使用 Python 製作聚餐費用試算器，透過字串處理、資料型別轉換、數值運算及布林比較，計算聚餐時每個人需要分攤的費用，並判斷是否超過個人預算。

使用 Google Colab 撰寫及執行程式。

## 三、程式功能

1. 去除聚餐名稱前後空白並轉成小寫。
2. 移除餐費中的貨幣符號與逗號，轉換成整數。
3. 將文字型態的人數轉換成整數。
4. 計算原始餐費 10% 的服務費。
5. 加上服務費後扣除折價券。
6. 計算每個人平均分攤的費用。
7. 判斷每人費用是否超過 300 元預算。

## 五、問題回答

### 問題一：為什麼需要進行資料型別轉換？

因為原始資料中的餐費和人數是字串，無法直接進行數學計算，所以需要先去除貨幣符號、逗號及空白，再使用 int() 轉換成整數，才能正確計算服務費與分攤金額。

### 問題二：為什麼服務費必須先計算，再扣除折價券？

因為題目規定服務費是原始餐費的 10%，所以必須先計算服務費，再扣除折價券。

**正確計算方式：**

服務費：1200 × 10% = 120 元

應付總額：1200 + 120 - 100 = 1220 元

**錯誤計算方式：**

如果先扣除折價券，再計算服務費：

(1200 - 100) × 1.1 = 1210 元

兩種算法相差 10 元，因此計算順序會影響最後的金額。
